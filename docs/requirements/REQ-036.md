# REQ-036 全核心个股追踪与飞刀式卡片切换

[← 返回需求总览](../../开发需求与生命周期.md)

**状态：已开发** | 日期：2026-11-24 | 范围：独立预览 | 关联：REQ-033、REQ-008、REQ-029

## 目标与现状

用户要求个股追踪覆盖全部近期核心和日内前排核心，保持一次只展示一只，点击卡片切到下一只，采用类似PPT飞刀式切换。

现有追踪读取涨停个股及十日榜，尚未连接完整近期核心池。近期核心股名点击用于展开自身详情；日内前排股名、涨停梯队和时间流点击用于选择追踪个股。现有行情刷新还会将不在涨停池/十日榜的选中股票重置，需要一并修正。

## 观察范围与顺序

- 追踪集合＝有效近期核心池 ∪ 全市场口径的日内前排池，按市场与股票代码去重；同一股票只出现一次，合并来源标签。
- 近期核心沿用REQ-033：风向标全量池、10日涨幅前五、20日涨幅前五及人工加入，应用已有人工排除规则；本需求不新增选股算法。
- 日内前排复用当前算法：涨停池按连板数降序、涨停时间升序取前8，并合并十日榜前五。提取成共享函数，避免列表与追踪使用两套规则；卡片以全市场口径覆盖全部，不随板块筛选缩小。
- 初始顺序为日内前排在前、近期核心按现有顺序补充在后。刷新时保留现有队列相对顺序，新成员追加，退出成员移除；刷新不因排名变化跳到另一只。
- 人工删除沿用“从近期核心排除”的含义；若仍属于日内前排，仍可作为日内前排被追踪，并明确显示该来源，不偷偷恢复其近期核心身份。

## 卡片交互与展示

- 保持一个固定尺寸的追踪卡片。标题区显示“个股追踪”、来源标签、序号（如3/28）、上一只/下一只按钮；底部简短提示“点击卡片看下一只”。
- 点击卡片主体一次前进一只，末尾循环到第一只；上一只可回看。获得焦点后支持左右方向键，按钮有明确可访问名称；不自动轮播。
- “飞刀式”按约250—350毫秒的倾斜飞出、下一张从侧面飞入设计，限制在卡片内部，避免遮挡邻近行情。系统开启减少动态效果时取消位移旋转。
- 动画期间连续点击按明确的忙碌状态忽略额外点击，完成后恢复，避免叠卡或顺序错乱；按钮、链接、文本选取及内容滚动不触发主体换股。
- 日内前排现有股名点击直接定位对应卡片；近期核心保留原展开详情行为，增加紧凑“追踪”入口定位该股。涨停梯队/时间流仍可临时查看队列外个股，标“临时查看”；点下一只返回原队列位置，不因此改变核心成员资格。
- 每张展示名称、代码、所属板块/来源、最新价格、涨跌幅、行情日期与时点；复用已有成交额、换手率、最高/最低、连板/涨停时间及10/20日榜信息。非涨停个股不硬套涨停原因，字段无数据标“未提供”或“—”。长原因文字在卡片内滚动，不撑高布局。
- 同时命中多个来源展示合并标签；榜单涨幅仅显示实际取得的区间值，不将未上榜误记为0或自行补造。

## 数据与刷新实现

- 统一前端追踪数据适配层，合并主行情快照与近期核心API。近期核心标签未打开时也能取得完整成员，不能依赖用户先点一次标签才有数据。
- 保留一分钟行情更新和现有后台报价缓存。切换优先立即展示缓存，已有新报价随后更新；不得每点击一张就完整重抓风向标、区间榜或全部股票。
- 覆盖队列所有成员的基础报价，复用全池报价与主行情任务；不足部分按股票去重、限并发后台补齐，当前展示股票优先。明确超时、失败保留旧值和来源时间，不能用采集时间冒充报价时间。
- 不调用模型，不新增付费服务。不得为动效阻塞行情/直播刷新；动画状态和数据刷新状态分离。
- 保留当前股票及队列位置；当前股退出集合时，切到原位置对应的下一只并提示退出。单股禁用切换，空池展示明确空态；一类来源暂时失败时保留其最近有效快照并显示过期，不把失败当成全部退出。
- 异步结果按股票身份与请求版本匹配，快速换股或旧请求晚返回不能把上一只的报价/说明填到下一只；同字段选择较新且交易日期匹配的数据，旧值保留时逐项标注日期，避免拼成虚假的当前行情。

## 验收标准

1. 两池所有有效股票均可访问，重复股票只计一次，多来源标签正确；人工新增/删除及日内前排独立来源语义正确。
2. 顺序点击可遍历整个并集，首尾循环、上一只和直接定位正确；临时查看不污染核心池。
3. 单张展示、飞刀切换、快速连点、文本选择/滚动、按钮点击、键盘及减少动态效果均正常，无叠卡或误切。
4. 分钟刷新、板块筛选和标签切换不丢失当前追踪；新增、退出、单股、空池、接口失败分别验证。
5. 首次打开不需要先访问近期核心标签；报价来自真实接口缓存，缺失与过期明确，异步返回不串股，切换不等待整轮取数。
6. 关联个股列表、涨停梯队、时间流原交互可用；核验桌面与窄屏布局，并在原预览页面验证实际加载版本。

## 风险与范围边界

接口字段不完整或交易日不同，会影响可显示的指标，但不影响该股进入追踪队列。本期覆盖当前两池及其最新可用行情，不承诺历史所有退出核心永久留池，不新增K线/分时图或行情归因。数据源调用量以复用缓存为主，补齐报价受现有通道预算约束；真实延迟及覆盖率在实现验收记录中报告，不预先承诺毫秒数。
