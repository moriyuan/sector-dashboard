# REQ-031 自动核心筛选、情绪地位验证与持续跟踪闭环

[← 返回需求总览](../../../开发需求与生命周期.md)

**状态：方案待确认** | 更新：2026-11-23 | 方案：v1研究草案 | 范围：独立预览及配套取数、回放工具

## 目标与用户纠正

用户说明九阳股份、东方海洋、北纬科技、冰山冷热只是举例，最终应依靠完整算法自行发现核心。本需求取代“人工名单就是重点核心”的产品定义；REQ-030已实现的分层、去污染、档案保留能力继续复用，但不能视为自动情绪核心识别已经完成。

核心的工作定义：在近期行情中已经形成显著高度或持续强势地位，且其强化、分歧、修复或走弱与其他市场参与对象反复出现可核验的先后联动，因而值得作为情绪观察锚点。算法输出观察地位，不输出买卖指令或获利概率。

闭环：全市场发现 → 多类型候选 → 高位地位及数据门槛 → 结构与影响证据评分 → 自动晋级 → 每轮支持/反证更新 → 走弱跟踪/修复/退役 → 盘后评价和版本校准。名单可以为空；没有证据时不凑足数量。

## 一、现状与证据边界

已只读核对项目KaipanlaSource、预览recent_selection/recent_service/ten_day_source，以及用户提供的kaipanla-data-sdk-0.1.0.zip。SDK覆盖情绪、历史复盘、板块、梯队、部分实时盘口，不等于已提供完整复权日线、全市场分钟历史和历史题材成员。

2026-11-23核验：本地完整收盘涨停缓存20个交易日（10月26日至11月20日）；核心逐股报价库仅覆盖11月23日，核验时7799条；快照库252条，日期跨度11月19日至11月23日。条数多不等于拥有足够独立交易日，也不能将局部核心报价当作全市场分钟样本。当前10/20日榜交易日核验失败。

因此，本次研究尚未给出实测有效的最优权重、准确率或已选出的新核心名单。以下窗口、权重和阈值均为待实现及验证的起始配置，不是已验证的交易规律。

## 二、证券范围与数据合同

| 数据 | 所需字段/时点 | 当前基础 | 本需求处理 |
| --- | --- | --- | --- |
| 证券与制度 | 代码、市场、上市/退市/停牌、风险警示、实际涨跌停价/制度、有效日期 | 目录和部分盘口已有，历史属性未齐 | 按当时制度分组；ST独立比较；无涨跌幅限制时期单列，不冒充普通连板 |
| 日级全市场 | 至少60个完成交易日的复权收盘/高低、量额、涨停、板数、复权因子版本 | 已有20日涨停结构，完整日线未验证 | 核验开盘啦能力、合法可用源和覆盖；不足时相应通道禁用，不能用涨停股代表全市场 |
| 分钟行情 | 来源时间、接收时间、成交价、累计量额、涨跌停状态 | 部分核心当日起持续采样 | 持续采集候选及对照成员；缺秒级数据只判分钟先后，不输出精确炸板次数 |
| 题材成员 | 当时可知的主/次题材、成员及生效时间 | 涨停股主归属、板块榜和部分分时 | 补完整成员快照；禁止用今天成分回填历史或只拿涨停同伴当对照 |
| 市场及同伴 | 同期市场/板块收益、广度、非涨停对照、样本覆盖率 | 广度和板块已有部分基础 | 联动计算要排除目标股票本身；不能将含本股的板块上涨全记为本股影响 |
| 监管与事件 | 官方来源、发布日期、事项类别、有效期；直播发布时间 | 自动监管未覆盖 | 作为风险与解释旁证；不因监管、热词或直播点名直接加核心分 |

每个字段记录event_time、received_at、available_at、source、状态和版本。所有时点运算只能读取available_at≤t的数据；修订行情不覆盖旧决策的证据版本。停牌/无成交/过期不能当零涨幅；复权与非复权分工：收益/趋势用同口径复权价格，涨跌停判定用当时制度和实际未复权价。

## 三、广泛发现候选，不由候选条件直接授予核心

自动每天盘前构建基础池，盘中增量更新，保留算法原始候选全集与进入原因，不仅从今日涨停名单找股票。

1. **连板高标通道**：近10日曾达到所在制度组连板高度前两档且≥3板；当日≥2板的前两档可先进入新生候选。低位只用于发现，后续有独立高位门槛。
2. **区间强势通道**：5/10/20日涨幅各组前1%与原10/20日前五的并集。原榜单前五继续在栏目内可见，不自动成为核心；组内排名不得冒称全市场供应商原排名。
3. **反复活跃/反包通道**：近20日≥3个收盘涨停日先召回；反包另依REQ-028跨日定义检测，不能用次数冒充反包。后续必须验证累计抬升、高位与持续性。
4. **趋势/容量通道**：20日相对收益组内前10%，至少最近5日中3日处于题材成交额前10%，或趋势结构候选；需要完整题材样本、统一复权日线。单日成交额大不能直接成为中军。
5. **历史核心通道**：先前自动认定的核心继续纳入复评，断板/退潮不从检测全集消失。新生首板只在当日观察，满足其他通道和晋级条件后才进入近期核心。

所有分位数按当时可见证券全集及可比交易制度计算，保留分母、缺样率与排名并列；小于30只的比较组标低样本，不据此单独晋级。没有完整全集时不声称“全市场前1%”。

## 四、先过地位门槛，再评分

自动重点核心须同时通过：证券/日期/价格质量合格、有至少一条结构通道、具有近期高位地位、具备充分的联动与验证证据。不能用高成交额补掉“没有地位”，也不能用高涨幅补掉“没有联动证据”。

**高位地位门槛H_gate：以下满足一条。**

- 近10日某天≥3连板、位于当日同制度组高度前两档，且该形成时点10日区间收益分位≥90%。
- 当前10日或20日收益分位≥97%，累计收益为正；用于断板反复活跃及趋势对象，不强制今天涨停。
- 曾经通过完整自动核心晋级，且距离最近一次有效核心证据≤20个交易日；只支持持续跟踪，不自动豁免重新激活条件。

价格绝对值高不是“高位”；低价股也可有较高相对空间。退潮市场最高只有1/2板时，不仅凭当日最高板强行认定高位核心。市场阶段（广度、涨停/炸板/晋级等）单独展示，首版不根据少量样本临时变更晋级门槛。

## 五、可解释评分与缺失处理

各分项0—100；权重固定、版本化，不由大模型自由调整。初始总分：

`S = 0.25H + 0.15R + 0.15P + 0.25L + 0.10D + 0.10A`

| 分项 | 定义与可复算的初始口径 |
| --- | --- |
| H 高位地位25% | 近10日高度排名得分与10/20日收益分位各占一半。高度按达到的档位、板数及形成距今交易日衰减：半衰期5日；高板但很久以前形成不永久占前排 |
| R 相对强度15% | 5/10/20日相对市场制度组中位收益分位均值；有完整题材时再与题材中位数取均值。分母及参照组固定，缺题材时标较低证据级别 |
| P 持续性15% | 最近10日相对收益为正天数占40%，每日收盘相对前5个完成交易日收盘最高值创新高的比例占30%，上涨日累计量额占比的组内分位占30%。频繁涨停但高度不抬升不能靠涨停次数拿满分 |
| L 联动影响25% | 按下一节独立事件验证：同伴跟随超额效应40%、跨事件复现率30%、领先方向一致性30%。同日同步上涨不计为领先事件；没有足够事件为未知，不默认0或50 |
| D 分歧承接/修复10% | 近10日有效板块分歧事件中，本股同期回撤相对同伴的优势占50%；此后恢复事件前价格的时间相对同伴占50%。尚未完成观察窗口的事件不计已修复，没有分歧样本为未知 |
| A 参与活跃度10% | 近5日成交额在题材内的分位中位数占50%，本股同时间段量额相对过去20日的分位占50%。只有总成交额不能生成逐股资金净流入 |

收益分位、同伴排名按可比组计算；同时保留原值。H与R使用相关价格信息，回放中做去掉H或R的消融检查；不能把六个分项声称为六条统计独立证据。

缺失分项不重分配权重抬高总分：显示已知贡献、完整度和分数可能区间，例如已知贡献58、未知权重25%，显示58—83/100而非“58分股”或“归一化77分”。未知因子数据库存null，区间下界只用于保守门槛判定，不解释为其真实表现为零。

质量C单独统计：必需输入覆盖率、来源新鲜度、同步误差、独立事件数和交易日覆盖。资格/联动关键字段缺失一票阻止新晋级；不能靠其他维度凑分。历史已确认核心遇数据故障标“证据待更新”，不因断网降为失效。

## 六、如何验证“它变了，市场是否跟着变”

先定义**可观察联动**，不把统计领先描述为确定因果。上行带动、下行情绪冲击分开存，不能给跌得多的股票加“强势分”；旧核心下跌后的影响用于风险跟踪。

1. 以过去数据估计市场/题材共同波动，构造本股与同伴残差收益。题材同伴组合排除本股，固定当时成员；优先至少5只同题材股票，并覆盖题材至少50%的已知成交额。覆盖不足时不能确认L。
2. 本股5分钟残差变化超过过去20日同时间段波动基准的2倍，且幅度超过该证券当日涨跌幅限制比例的10%，记录上行/下行事件。波动基准至少5个有效交易日，达不到只记线索。没有涨跌幅限制时不套此阈值，单列待验证。
3. 只在同伴事前5分钟未已显著启动时，将本股记为领先候选；同一分钟观察到的变化记“同步、先后未知”。结合新封板观察可以加事件备注，但分钟采样不还原逐笔首次封板。
4. 比较事件后1/3/5分钟同伴残差收益、跟随上涨比例及新增涨停，与事前窗口及相同市场/题材状态的对照窗口比较；同期整体普涨不能全归到本股。
5. 事件后的窗口未完成时状态为待验证，必须等实际未来样本到达后才进入已知证据。重叠事件至少间隔10分钟，同一波拉升只计一次；跨股票同主题同一波事件归簇，不能反复计票。
6. L可用于晋级的起始要求：近10日≥6个独立可评事件、覆盖≥3个交易日，分块重采样的同伴跟随超额效应95%区间下界>0，领先方向检验在当轮比较族中经多重检验控制后通过（初始FDR目标0.10）。数据不足显示“联动样本不足”，不以6次都涨就宣称统计显著。
7. 分钟网格、统计族（候选×题材×窗口）、随机种子、事件去重、检验次数及负向事件单独留档。过去20日用于估计的参考窗口也不得读未来。模型可以解释已有证据，不能替程序认定显著性或补全成员。

这些统计要求是研究起点，未证明适用于当前A股所有行情；样本不足时的正确输出是候选/待验证。若真实数据无法满足，将如实保留未完成状态，不能回退成“只改成手工核心就交付”。

## 七、自动晋级与生命周期

| 状态 | 初始进入/变更规则 | 页面与后续行为 |
| --- | --- | --- |
| 新候选 | 命中召回通道 | 解释入选通道和数据覆盖，不能直接贴龙头 |
| 结构强势、联动待验证 | H_gate通过；H/R/P合成结构得分≥75；L尚不足 | 放候选层优先展示，系统主动收集后续事件；不是人工兜底 |
| 自动重点核心 | H_gate通过；S保守下界≥75；C≥85%；L≥60且统计/事件门槛通过；至少间隔5分钟的两次完整评价通过 | 不需要人工确认，显示自动角色、支持/反证及算法版本；允许空名单 |
| 强化/分歧跟踪 | 核心地位与当前状态分离；显著负向事件或连续15分钟强度弱于题材标分歧，避免一分钟涨跌引起身份抖动 | 仍在核心区，突出风险状态，不删除亏钱样本 |
| 历史核心/退潮跟踪 | 数据完整条件下连续2个收盘综合分<60且无新增有效联动支持，或最近有效核心证据距今>10个交易日 | 转历史组保留原认定日期及退潮过程；停牌/断网不按失效计时 |
| 再激活 | 再次满足完整晋级门槛 | 追加再激活事件，不重置历史首次入选 |
| 归档 | 连续20个有效交易日无新核心证据，且不在人工关注 | 退出默认活跃展示；档案、历史报价和决策记录保留，可检索 |

不同角色用“连板高标核心、反复活跃核心、趋势容量核心、修复中的历史核心”等标签表达；反包、容量标签必须有各自数据证据，不由名字/语言模型猜测。

人工关注是独立布尔标记，不能给算法加分、放宽门槛、自动升级为自动核心。人工排除控制用户视图与跟踪请求，算法研究结果仍保留“符合但用户排除”的审计记录，不能自动加回页面。

四只举例股票不写入v3筛选白名单，不参与“必须选中”验收；迁移时将REQ-030一次性示例加入身份转为“人工关注/示例历史”，随后与所有股票用同一算法重评。真实手动添加的关注关系保留；无论示例是否入选，都输出实际理由，不为匹配示例反向调参。

## 八、刷新、存储和前端反馈

- 每分钟行情主刷新保持独立；本地轻量特征和候选状态可随快照更新，重统计/联动检验每5分钟或有效独立事件后后台运行，收盘更新日级特征。不得每分钟调用DeepSeek选股。
- 首版保留既有取数并发、限速、超时和模型预算；优先核验批量/增量接口。全市场日级批处理、事件同伴取样不串入行情主刷新。新增分钟样本采集先测预算，优先近期核心，其次轮换候选/同伴；无法覆盖的样本明确列出，不能默默截断却声称全市场已验证。
- 默认不增加付费源/模型费，不改变一分钟核心报价承诺。若来源只能逐股调用导致预算不可满足，先交付取数测量与替代方案，按实质范围/成本变更再确认，不悄悄提高请求频率。
- 存储证券时点属性、市场全集快照、日/分钟事实、特征、事件待验证队列、评分、状态迁移、人工覆盖和版本。原行情按原存储策略；特征与决策增量追加，键为证券+时点+版本，复用行情不重复保存整库。用实测压缩字节/条×股票数×交易分钟数估算新增存储，未实测不承诺具体MB。
- 前端保留同一近期栏目，显示自动重点、待验证候选、历史核心、人工关注；一个股票去重展示多个身份。排序为自动核心地位及风险优先，人工置顶独立标识，不用人工身份冒充算法排序。
- 每行给“角色、当前状态、数据等级”，详情展示核心理由/反证、形成时间、最新验证、评分已知贡献与未知部分、同伴反应时间轴、升降级原因、数据缺口。候选页面直说“还差什么才能晋级”。榜单前五仍可查看。
- 历史回放严格按当时可用数据及算法版本复现；不得在过去插入今天确认的核心、题材成员或后验标签。

## 九、研究验证与验收，不以选中四个例子为目标

1. **数据门**：完成字段能力报告、日期/制度/复权核验和覆盖率评估。目标准备≥60个完成交易日全市场日级数据、≥20个交易日候选及对照分钟数据作为首批实验；这只是启动门槛，不等于统计充分。无法补历史时开始真实前向积累，并明确长期验证未完成。
2. **基准对比**：与“连板排序”“10/20日涨幅排序”“REQ-030规则候选”“同规模随机候选”比较，按相同K值、全集、数据时点和缺样率评价；人工名单不作为算法优势来源。
3. **时间隔离**：按交易日滚动训练/校准/验证；验证集不用于调参。以最长标签前瞻窗口清除边界重叠，以最长特征回看期完成预热；一天中的多分钟样本不能随机分到训练与测试两侧。记录所有试验次数，不只汇报最好一组。
4. **评价目标**：主要看核心识别准确率/召回率、与盲评时点标签的一致性、核心形成后发现延时、低位普通首板误入率、旧核心走弱保留率、身份抖动、数据缺失时误晋级率；未来同伴反应仅作后验验证，不作历史当时特征。收益和回撤是辅助，不能用后来涨得多倒推当时必是核心。
5. **标签控制**：将用户举例仅保留为研究案例；人工评价在隐藏算法分数及未来行情后标注核心/非核心/不确定，允许分歧，不用单人的几个答案作为唯一真值。冻结独立评估集后才进行最终比较。
6. **通过门槛**：未来信息泄漏、普通首板仅凭封板早晋级、人工关注直接改变自动分数、缺关键数据自动晋级均必须为0；样本外Precision@K至少不劣于最强简单基准、Recall在同等名单规模下改善且日级分块区间支持改善，列出发现延时/抖动的代价。证据不支持改善时如实报未通过，不更换测试集凑结论。
7. **消融与敏感性**：移除L、去掉某价格分项、改变窗口与阈值小范围扰动，检查效果是否来自单一指标或少数日期；高低情绪阶段、不同制度组分别报告。若大量试验，增加多重比较/回测过拟合评估，不能只做一次留出测试就声称稳健。
8. **前向影子运行**：先记录v3选择及解释，保持当前展示可回退；至少10个交易日运行观察并报告缺样和误选，未完成不标“全闭环验证通过”。足够证据后再建议切换默认算法，遵守用户验收及原预览更新授权范围。

## 十、开发分段与关联范围

本条按一个完整闭环验收，以下为执行阶段，不在总览重复计数：A数据能力/取数补齐 → B结构召回/特征/回放 → C联动与状态机 → D影子对比/前端/迁移。A或B完成不标本条完成，C数据不足也不以人工核心替代交付。

REQ-019提供昨日及跨日样本，REQ-020提供趋势/容量筛选，REQ-021提供联动证据基础；本条只包含为核心算法所需的部分，不代表其各自完整功能已交付。REQ-022精确封单/资金流/逐笔事件不是首版硬依赖，缺失明确标注。正式集成依旧是REQ-018，不随本条自动合入。
