## 同花顺概念切换（2026-10-30）

概念视图、热力图、历史走势、热点冷点和个股概念归属默认使用同花顺；一级行业仍使用东方财富。概念目录按同花顺官网 CID 精确合并公开资金目录、概念导航与新增概念列表，本次取得390个概念。CID 与指数代码分别校验，内部代码使用 `THS` 前缀。指数日线金额为元；当日接口日期和源时间必须满足收盘口径。

成分逐页校验页码、序号、去重及目录数量；小于等于10只的无分页列表须与独立目录数量完全一致。验证页、分页缺失或数量不符时保留空白，不给未核验成分生成广度、评分或个股归属。完整性受公开来源限制，页面显示行情与评分覆盖率。

本机10月30日迁移验收：390/390个概念具有当日报价和日线（15–251根，取决于该概念指数的可用历史），102个概念成分核验通过并可评分，其余288个待核验，主要受成分页访问验证限制。个股榜采用已核验的31个东财行业、102个同花顺概念。核验摘要为 `runtime/qa/ths-migration-20261030.json`；后续采集可能增加覆盖。

同花顺概念尚无已验证日期的资金流接入，净流入区域明确留空；成交额占比使用核验成分计算。历史东方财富概念快照独立保存，不转换名称或拼接资金。默认 API 返回同花顺；`concept_source=eastmoney` 仅用于显式查看历史东财快照，旧个股榜点击其概念时保留原来源和修订。


`collect-ths` 采用3个工作线程和全局请求间隔；只采集最近已完成交易日，不用当前成分重建历史。15:30与16:30缓存分开复核，原始页面、采集时间和版本存入SQLite；不读取浏览器登录状态或绕过来源验证。请避免与自动采集同时运行全量批次。

## 口径与历史边界

规则 `sector-v1.0`：当日涨幅百分位 40% + 此前五个完整交易日收益百分位 30% + 非 ST 有效成分上涨比例百分位 30%；缺少必要值不评分，不重分配权重。百分位按平均名次映射到 0–100，同值全并列为 50；行业、概念分别计算。热点要求强度前 20%且当日上涨。

持续性展示 5/10/20 日收益、近 10 日涨幅前 20%次数、连续强势收盘日和相对前 20 日最高收盘点位的变化。需要连续交易日数据；连续天数仅使用已完成的收盘数据。冷门条件需要连续五个收盘日后 30%且自身 60 日成交额占比后 20%；冰点候选要求当日后 20%、上涨比例≤20%、较此前 20 日最高收盘价回撤≥5%。这些是描述标签，没有经过反弹预测验证。

市场广度限沪深 A 股，ST 单列；价格、涨跌幅、成交额有效且成交额大于零才进入涨跌比例分母，平盘进入分母。涨跌停优先使用完整覆盖的供应商涨跌停价，否则明确显示池内计数；炸板率为“未封住的曾涨停去重数 / 曾涨停去重数”，已回封股票不计入分子。池数据缺失与真实空池区分。主力资金仅表示东方财富统计口径，不识别机构交易。

板块原始指数、原始成分涨跌计数与筛选后的成分广度分别显示。概念存在重叠，成交额与资金不可跨概念相加；成交额占比以同日全市场成交额为分母，不以板块金额相加代替。

历史快照按照收盘日期及修订 ID 读取，保留每次修订；已有盘中归档留在数据库，但不在当前页面和只读 API 中展示。详情固定引用当时保存的成分版本、行情、涨停池和日线版本。上线前仅能回看供应商指数历史，不用今天的成分重建过去，历史资金和情绪保持空白。历史指数排名基于**当前目录内指数**，不是一套已验证的历史全量板块目录。没有当时目录的日期不适合直接用于无幸存者偏差的策略回测。

## 运维与验证

```sh
.venv/bin/python -m backend.cli probe
.venv/bin/python -m backend.cli collect
.venv/bin/python -m backend.cli recover --limit 1
.venv/bin/python -m backend.cli backfill --limit 10
.venv/bin/python -m backend.cli import-browser --directory runtime/browser_exports
.venv/bin/python -m pytest -q
cd frontend && npm run build
```

浏览器归档导入为离线恢复工具，只读取已保存的公开 JSON，不访问浏览器认证状态。文件格式为 `{source_url, captured_at, response}`；导入拒绝未知来源、重复/缺失分页、分类重叠和代码不匹配。`backfill --limit` 约束本次日线/成分尝试数量；若来源失败则停止并保留已成功的数据。

`recover` 恢复最近一个已完成交易日：板块→成分→全市场→指数→情绪池→缺失日线→资金→重新计算。日线通道首次失败即停止该批回补；其他来源继续。默认不重建任意历史成分。运行时调度仍仅在交易日盘后进行；来源失败按退避重试，补全结果在冷却结束后发布。

只读 API：`GET /api/market`、`GET /api/sectors`、`GET /api/sectors/{code}`、`GET /api/dates`、`GET /api/status`、`GET /api/gainers`。个股榜支持 `limit`（1–500）、`include_st`、`sector`、`q`、`revision`。行情 API 支持 `date=YYYY-MM-DD&mode=close`（省略模式也读取收盘；`live` 返回 422），板块支持 `kind=industry|concept`、`concept_source=ths|eastmoney` 和 `revision`。源时间未知明确返回 null，采集时间不替代交易日期；资金、指数、情绪各带自己的来源元数据。

验证：61个后端测试通过，前端生产构建通过。覆盖：百分位并列、ST/停牌/零分母、重复成分、回封去重、闭合日收益、缺失交易日、60 日历史不足、资金单位、分页完整性、池日期、历史/模式隔离、同秒修订固定、离线导入和重启读取。浏览器检查记录与截图位于 `runtime/qa/`。

接口参考：[板块数据](https://akshare.akfamily.xyz/data/stock/stock_board.html)、[资金流](https://akshare.akfamily.xyz/data/stock/stock_flow.html)、[涨跌停池](https://akshare.akfamily.xyz/data/stock/stock_quote.html)。适配器保留 AKShare 包装常丢失的源时间和代码字段，日历使用 AKShare 的新浪解码器。


## 新闻研究（`#news`）

默认打开涨幅榜找新闻。按北京时间选取当天已归档的沪深收盘涨幅前 20 只非 ST

直接提及与已核验板块词命中分列，列出原文依据和相对收盘的发布时间。快讯与
行情复述均不能单独解释股价原因。未归档日期显示空状态，可选择历史交易日；
历史视图仅使用截至该日已入库的行情、报道修订和合并关系。个股榜的“按本榜找新闻”
沿用所选日期，“全部新闻”可打开原来的事件流。只读接口为 `GET /api/news/gainers?date=YYYY-MM-DD`。

运行 `./start.sh` 同时启动独立新闻 worker 和网页服务。新闻全天采集，国内
2 分钟、海外 10 分钟；行情仍仅盘后运行。`SECTOR_DISABLE_NEWS=1` 可只启动网页。
单独采集验证：`python -m backend.news_worker --once --limit 10`。worker 通过 SQLite
任务状态及文件锁防止同库重复运行，分析串行在独立线程执行，不阻塞来源轮询。

只读接口为 `/api/news`、`/api/news/{event_id}`、`/api/news/sources`。列表默认最近
24 小时；`window=all` 查看所有已采集记录，`date=YYYY-MM-DD` 是截至当天收盘后的
当日历史视图，`asof` 可固定知识时点。尚未采集的旧事件不会加入当时视图；全部
已采集视图中的补采条目有标记。直接提及、业务相关和产业链推导独立展示。外文
新闻在模型完成前显示来源原文，分析完成后显示中文；无法确认跨语言同一事实
时保留独立事件，只有同一规范链接或标题摘要完全一致的近期报道确定性合并。

DeepSeek Key 只从 worker 环境变量 `DEEPSEEK_API_KEY` 读取。请求前按 UTF-8 字节
上界、输出上限和 2026-11-02 官方峰值价格预留费用；北京时间每天限额 1 美元，
未知用量继续占用预留，失败最多重试 3 次。价格或模型别名变化需重新核对。
未配置或达到预算时采集、明确匹配继续运行。价格来源：
https://api-docs.deepseek.com/quick_start/pricing/ 。模型结果必须通过本地代码与
证据编号白名单校验；最终未选择的候选不会作为关联股票发布。

`backend/news_mapping.json` 是独立版本化人工核验业务证据，首批覆盖八题材各
两家产业代表。它不是同花顺成分表，也没有据此宣称产业龙头。机器人执行器
仅作产品上下游推导，不证明任何特定海外客户关系。更新资料须新增映射 id，

## 龙虎榜

本机侧栏「龙虎榜」、个股涨幅榜的股票名称和新闻研究页的个股入口通向同一日期的披露详情。
使用东方财富公开数据中心的沪深 A 股龙虎榜，完整核对当日榜单及买、卖两侧分页。按披露编号、
股票、日期和原因匹配席位，按来源给出的买入额、卖出额和净买额显示，金额单位为万元。
单日、明确连续三个交易日和其他周期分开，每种原因独立展示。重复出现的席位和跨周期金额不累加。
个股详情同时展示同日收盘排名和现有新闻库近三个自然日的公司报道、同行业与概念线索。

“上涨原因与证据”先找所选交易日的异动报道：要求能定位到本股的上涨描述和具体事件，区分“报道明确归因”和“报道列为行情背景”。每条可核对事实、报道中的行情片段、来源、发布时间和原文；存在多条解释时分别列出。仅并列事件和股价的标题保留为待核实线索。昨日行情、单纯播报涨停、盘后新披露都不能解释当天上涨；当天盘后回顾单列时间。近三日其他报道仍可查阅。

只在找到本股线索后，才从当日非 ST 涨幅前 100 名里查找其他股票：原文需把该股上涨放在同一催化的报道段落中，或另一篇报道需记载同一可辨认的具体事实。行业／概念归属和名次不构成关联证据。个股特有事件允许没有同伴；原因待核实时显示空列表。每只同伴均可查对应报道，包括未上龙虎榜的股票。股票与新闻跳转保留复盘日期，历史归因仅使用截止时已收录的修订和原文补证（规则 move-news-v1）。

交易日 15:30 起，网页服务的独立后台线程自动查询，待披露、部分披露或失败时每 5 分钟复查，
已有披露后每 30 分钟核验。网络故障单独标示，缺少席位保留未知；已有同一项席位可标明沿用
上次快照。只按对应交易日归档，数据变化新增修订，重复轮询不重复写榜单。历史补采显示真实
采集时间；显式 `asof` 只读取该时点已有的存档。公开源没有提供实际发布时间。
只读接口为 `GET /api/lhb?date=YYYY-MM-DD` 和 `GET /api/lhb/{code}?date=YYYY-MM-DD`。
可运行 `.venv/bin/python -m backend.cli collect-lhb --date YYYY-MM-DD` 补采指定已收盘日期。

## 国家队资金观察（宽基 ETF）

“资金”下方新增宽基 ETF 区域，随顶部复盘日切换。首批为 510300、510310、510330、
159919、510050、510500、512100、588000、159915、159338，共 10 只代表产品和 7 类宽基。
展示份额变化、估算净申赎、成交额、前 20 个完整交易日均额和成交倍数，并可按指数筛选。
固定样本并非全市场 ETF；投资者身份仅凭可核验的定期报告披露，不由每日流入推断。
已核验的历史持仓示例为 510300 的 2025 年年度报告，明确标示报告期和公告日期。

份额来自沪深交易所按日历史表（原单位万份，内部转为份），净值来自天天基金的基金专属
公开净值序列，成交量额来自腾讯未复权日线（成交额万元转元，以成交均价上下界校验）。
估算净申赎采用“份额日增量 × 当日单位净值”，包含实物申赎折价。
成交放量默认阈值为当日成交额达到前 20 日均额 1.5 倍（排除当日），规则 etf-flow-v1。
净值缺失、日期断档或份额拆分/折算疑点留空；失败可沿用同日输入并显示缺口，修订追加存储。

网页服务运行期间在交易日 16:30 后采集、19:30 后复核，次交易日 09:00 后确认前日深市
初值。失败每半小时重试。未运行的时段可显式回补：
`.venv/bin/python -m backend.cli collect-etf --date 2026-11-02 --days 20`。只读接口为
`GET /api/etf-tracker?date=YYYY-MM-DD`，读取所选交易日已保存版本。
